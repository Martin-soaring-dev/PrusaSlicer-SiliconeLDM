# PrusaSlicer 架构分析与硅胶模式改动方案

> 日期：2026-06-02
> 状态：架构分析完成，准备开始改动

## 一、现有挤出管线分析

### 1.1 数据流

```
PrintConfig (配置)
  │
  ▼
Flow::new_from_config_width()  ──→  Flow 对象 (width, height, spacing, nozzle_diameter)
  │
  ▼
Flow::mm3_per_mm()             ──→  挤出截面积 (mm³/mm)
  │
  ▼
Extruder::e_per_mm(mm3_per_mm) ──→  E轴步进量 (mm filament / mm movement)
  │
  ▼
GCode.cpp: _extrude()          ──→  dE = e_per_mm × line_length × e_fraction
  │
  ▼
GCodeWriter::extrude_to_xy()   ──→  "G1 X{x} Y{y} E{emitE}"
  │
  ▼
GCodeFormatter::emit_e()       ──→  格式化 E 值输出
```

### 1.2 回抽/去回抽管线

```
Extruder::retract()             ──→  计算回抽量
  │
  ▼
GCodeWriter::retract()          ──→  "G1 E-{retract_length} F{retract_speed}"

Extruder::unretract()           ──→  计算去回抽量
  │
  ▼
GCodeWriter::unretract()        ──→  "G1 E+{unretract} F{deretract_speed}"
```

### 1.3 压力提前管线

```
GCode.cpp 生成完整 G-code
  │
  ▼
PressureEqualizer::process_layer()
  │  解析 G-code 文本
  │  计算体积挤出速率变化
  │  调整 F 值以平滑挤出速率斜率
  ▼
输出调整后的 G-code
```

## 二、硅胶模式改动方案

### 2.1 核心原则

- **几何处理层零改动**：PerimeterGenerator、Infill、SupportMaterial、Layer 等不动
- **挤出物理层翻转**：Flow 不再计算 mm3_per_mm，改为计算 speed
- **G-code 输出层切换**：不输出 E 值，输出 M106/M107/G4/F
- **通过 `--silicone-mode` 开关隔离**，默认关闭

### 2.2 硅胶挤出管线（目标）

```
PrintConfig (配置 + 硅胶参数)
  │
  ▼
Flow 对象 (width, height, spacing, nozzle_diameter)
  │
  ▼
硅胶模式: speed = flow_rate / (width × height)    ← 替代 mm3_per_mm()
  │  clamp(speed, min_speed, max_speed)
  ▼
GCode.cpp: _extrude()          ──→  硅胶模式分支
  │
  ▼
GCodeWriter::extrude_to_xy_silicone()  ──→  "G1 X{x} Y{y} F{speed}"  (无 E)
```

### 2.3 硅胶回抽/去回抽管线（目标）

```
回抽 (原 retract):
  M107              ; 关气泵
  G4 P{off_delay}   ; 等待余料停止 (400ms)
  [M106 P2 S255     ; 开真空阀 - 待标定]
  [G4 P{vacuum}     ; 真空回抽延时]
  [M106 P2 S0       ; 关真空阀]

去回抽 (原 unretract):
  M106              ; 开气泵
  G4 P{on_delay}    ; 等待出料稳定 (150ms)
```

### 2.4 硅胶压力提前（目标）

```
PressureEqualizer 在硅胶模式下：
  跳过（或改为速度斜坡逻辑）
  挤出开始: F 从 min_speed 渐变到 target_speed (在 ramp_length 内)
  挤出结束: F 从 target_speed 渐变到 min_speed
```

## 六、代码级发现（2026-06-02 源码阅读）

### 6.1 配置系统

PrintConfig 使用宏定义系统：
- `PrintConfig.hpp` 中用 `PRINT_CONFIG_CLASS_DERIVED_DEFINE(PrintConfig, (MachineEnvelopeConfig, GCodeConfig), ...)` 定义配置项
- `PrintConfig.cpp` 中用 `def = this->add("name", coType)` 设置默认值、标签、tooltip
- 配置项类型：`ConfigOptionBool`、`ConfigOptionFloat`、`ConfigOptionFloats`（per-extruder）、`ConfigOptionFloatOrPercent` 等

### 6.2 挤出管线关键代码

**Flow::mm3_per_mm()** — 计算挤出截面积：
```cpp
// Flow.cpp ~145
double Flow::mm3_per_mm() const {
    float res = m_bridge ?
        float((m_width * m_width) * 0.25 * PI) :
        float(m_height * (m_width - m_height * (1. - 0.25 * PI)));
    return res;
}
```

**Extruder::extrude(dE)** — 累积 E 值：
```cpp
// Extruder.cpp ~20
std::pair<double, double> Extruder::extrude(double dE) {
    if (m_config->use_relative_e_distances) m_E = 0.;
    dE = GCodeFormatter::quantize_e(dE);
    m_E += dE;
    m_absolute_E += dE;
    return std::make_pair(dE, m_E);
}
```

**GCodeWriter::extrude_to_xy()** — 输出 G1 X Y E：
```cpp
// GCodeWriter.cpp ~210
std::string GCodeWriter::extrude_to_xy(const Vec2d &point, double dE, ...) {
    m_pos.head<2>() = point.head<2>();
    GCodeG1Formatter w;
    w.emit_xy(point);
    w.emit_e(m_extrusion_axis, m_extruder->extrude(dE).second);
    w.emit_comment(this->config.gcode_comments, comment);
    return w.string();
}
```

**GCode::_extrude()** — 主循环中调用挤出：

### 6.3 改动策略确认

硅胶模式需要在以下位置插入分支：

1. **GCode::_extrude()** (~3559行)：设置速度后、挤出移动前，判断 `m_config.silicone_mode`
   - 硅胶：跳过 E 值计算，用 `speed_for_silicone()` 计算 F，调用 `extrude_to_xy_silicone()`
   - FDM：保持原逻辑

2. **GCode::retract_and_wipe()** (~3860行)：回抽时判断
   - 硅胶：调用 `retract_silicone()` → M107 + G4 P{off_delay}
   - FDM：保持原逻辑

3. **GCodeWriter** 新增三个方法：
   - `extrude_to_xy_silicone()` — G1 X Y F（无 E）
   - `retract_silicone()` — M107 + G4 P{off_delay}
   - `unretract_silicone()` — M106 + G4 P{on_delay}

4. **Flow** 新增 `speed_for_silicone()` — F = Q / (W × H)

5. **Extruder** 硅胶模式下 `extrude()`/`retract()`/`unretract()` 返回 (0,0)

6. **PressureEqualizer** 硅胶模式下跳过（无 E 值可平滑）
