### 2. `src/libslic3r/PrintConfig.cpp` (+92 行)

**位置：** `z_offset` 默认值之后，`perimeter_generator` 之前

为所有硅胶配置项添加默认值、标签、tooltip、取值范围。默认值基于用户标定参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `silicone_mode` | `false` | 默认关闭，不影响 FDM |
| `silicone_flow_rate` | `7.44` | 20psi, 0.84mm 喷嘴, 10mm/s × 1.24mm × 0.6mm |
| `silicone_pressure_on_delay` | `150` | 开气到出料稳定 |
| `silicone_pressure_off_delay` | `400` | 关气后余料停止 |
| `silicone_vacuum_retract_time` | `0` | 待标定，默认关闭 |
| `silicone_min_speed` | `2` | 最慢速度 → 最宽线宽 |
| `silicone_max_speed` | `30` | 最快速度 → 最窄线宽 |
| `silicone_speed_ramp_length` | `2` | 启停速度斜坡长度 |
| `silicone_min_speed_ratio` | `0.3` | 斜坡起始速度比例 |

### 3. `src/libslic3r/Flow.hpp` (+4 行) + `Flow.cpp` (+18 行)

**Flow.hpp：** 新增方法声明
```cpp
float speed_for_silicone(float flow_rate_mm3_per_sec, float min_speed, float max_speed) const;
```

**Flow.cpp：** 新增方法实现（在 `mm3_per_mm()` 之后）
```cpp
float Flow::speed_for_silicone(float flow_rate_mm3_per_sec, float min_speed, float max_speed) const
{
    if (flow_rate_mm3_per_sec <= 0.f || m_width <= 0.f || m_height <= 0.f)
        return 0.f;
    float speed = flow_rate_mm3_per_sec / (m_width * m_height);  // F = Q / (W × H)
    if (speed < min_speed) speed = min_speed;
    if (speed > max_speed) speed = max_speed;
    return speed;
}
```

### 4. `src/libslic3r/Extruder.hpp` (+4 行) + `Extruder.cpp` (+12 行)

**Extruder.hpp：** 新增 `m_silicone_mode` 成员变量和 getter/setter

**Extruder.cpp：** 三个方法添加硅胶模式早期返回：
- `extrude(dE)` → 硅胶模式返回 `(0, 0)`
- `retract()` → 硅胶模式返回 `(0, 0)`
- `unretract()` → 硅胶模式返回 `(0, 0)`

### 5. `src/libslic3r/GCode/GCodeWriter.hpp` (+6 行) + `GCodeWriter.cpp` (+96 行)

**GCodeWriter.hpp：** 新增 5 个方法声明

**GCodeWriter.cpp：** 新增 5 个方法实现

| 方法 | 输出 |
|------|------|
| `extrude_to_xy_silicone()` | `G1 X{x} Y{y} F{speed}` (无 E) |

## 硅胶 G-code 输出格式

### 挤出移动
```gcode
M106              ; turn on pressure (silicone unretract)
G4 P150           ; wait for pressure on
G1 X41.7 Y84.944 F600  ; extrude move (F = Q/(W×H) × 60, no E axis)
```

### 回抽
```gcode
M107              ; turn off pressure (silicone retract)
G4 P400           ; wait for pressure off
```

### 真空回抽（可选，vacuum_retract_time > 0 时）
```gcode
M107              ; turn off pressure (silicone retract)
G4 P400           ; wait for pressure off
M106 P2 S255      ; vacuum valve ON
G4 P100           ; vacuum retract
M106 P2 S0        ; vacuum valve OFF
```

## 使用方式

### PrusaSlicer 命令行
```bash
prusa-slicer --silicone-mode=1 \
             --silicone-flow-rate=7.44 \
             --silicone-pressure-on-delay=150 \
             --silicone-pressure-off-delay=400 \
             --silicone-min-speed=2 \
             --silicone-max-speed=30 \
             model.stl
```

### 配置文件 (.ini)
```ini
silicone_mode = 1
silicone_flow_rate = 7.44
silicone_pressure_on_delay = 150
silicone_pressure_off_delay = 400
silicone_vacuum_retract_time = 0
silicone_min_speed = 2
silicone_max_speed = 30
silicone_speed_ramp_length = 2
silicone_min_speed_ratio = 0.3
```
