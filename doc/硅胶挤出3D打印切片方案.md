## 一、背景与问题

### 1.1 研究背景

博士论文第六章涉及踝足矫形器（AFO）/鞋垫的硅胶 3D 打印制造。打印系统采用**气动挤出**方式：压缩空气推动针筒中的硅胶材料通过喷嘴挤出，在打印平台上逐层堆积成型。

### 1.2 核心问题：FDM 切片软件与硅胶挤出的范式不匹配

现有主流切片软件（PrusaSlicer、Cura、Slic3r）均基于 **FDM（熔融沉积成型）** 范式设计：

| | FDM 范式 | 硅胶气动挤出范式 |
|---|---|---|
| **可控变量** | 挤出量 E（步进电机，响应快） | 移动速度 F（响应快） |
| **不可控变量** | — | 流量/压力（大延迟、非线性） |
| **线宽调节方式** | 变 E，F 不变 | **变 F，E 不变** |
| **物理模型** | `E = f(移动距离, 层高, 线宽, 丝径)` | `线宽 ∝ 挤出速率 / 移动速度` |

**根本矛盾：** FDM 切片软件通过调节挤出量（E 轴）来控制线宽，而硅胶气动挤出需要**保持恒定挤出量、通过调节移动速度（F 轴）来控制线宽**。

### 1.3 硅胶打印的特殊需求

硅胶气动挤出有以下 FDM 没有的物理特性：

| FDM 概念 | 硅胶对应 | 实现方式 |
|---|---|---|
| 回抽（retraction） | 真空阀开启 + 延时 | `M107` + `G4 Pxxx`（待标定，约 100ms） |
| 压力提前（pressure advance） | 开气后移动等待 + 速度斜坡 | `M106` → `G4 P150` → 渐变 F 值 |
| 挤出（extrusion） | 恒压 + 变速 | 固定气泵输出，F 随目标线宽变化 |
| 擦嘴（wipe） | 关气 + 短距离空驶 | 关阀后走一段不挤出 |

### 1.4 已有基础

- **PrusaSlicer 优化配置 + 手动后处理**：已能基本满足需求
- **标定参数**（20psi, 0.84mm 喷嘴, 30CC/50CC 针筒）：
  - 最佳移动速率：10 mm/s
  - 开气延迟：150 ms
  - 关气延迟：400 ms
  - 真空回抽时间：待标定
- **参考代码**：邹子宁 MATLAB 切片程序（STL 读取、三角形-平面求交、图论路径连接）

## 二、方案对比

### 2.1 方案 A：G-code 后处理器

**思路：** PrusaSlicer 正常切片 → Python 脚本后处理 G-code

**致命缺陷：**
1. **变线宽不可知**：PrusaSlicer 在薄壁/填缝处动态调整线宽，但 G-code 中只有 X/Y/E/F，没有"目标线宽"信息。虽可从 ΔE 反推线宽，但——
2. **路径规划不感知物理约束**：PrusaSlicer 决定"这里需要 0.3mm 线宽"时，不知道硅胶系统能否实现（受限于速度上下限）。路径间距已经按 FDM 可实现的线宽范围生成，后处理无法改变路径几何。
3. **填缝路径缺失**：关闭填缝 → 窄缝处无路径 → 打印缺料。开启填缝 → 路径按 FDM 线宽生成，翻译为速度后可能超出物理极限。

**结论：** 后处理只能做"翻译"，不能做"规划"。路径规划必须感知物理约束。

### 2.2 方案 B：独立切片器（Python 从零写）

**思路：** 用 Python 从零实现 STL 读取 → 切片 → 路径规划 → G-code 生成

**优点：**
- 硅胶物理模型是一等公民
- 代码完全可控，论文创新点清晰

**缺点：**
- 需从零实现大量计算几何功能（轮廓偏置、填充图案、支撑、接缝优化等）
- 这些功能 PrusaSlicer 已打磨十年，重写不产生论文价值
- 工作量大（估计 1500+ 行），且很多代码与"硅胶挤出"无关

### 2.3 方案 C：修改 PrusaSlicer 源码 ✅ 最终选择

**思路：** Fork PrusaSlicer，在 `libslic3r` 中添加硅胶挤出模式

**核心洞察：** 几何处理层（切片、周长、填充、支撑）完全不动，**只改挤出物理层和 G-code 输出层**。

**优点：**
- 所有几何能力免费获得（十年打磨的计算几何代码）
- 改动集中在 5-8 个文件，范围可控
- 通过 `--silicone-mode` 开关隔离，默认关闭不影响 FDM
- 作为独立作品挂在 GitHub，不追上游更新
- 论文创新点清晰："基于 PrusaSlicer 的硅胶气动挤出 3D 打印切片系统"

**缺点：**
- 需理解 C++ 代码库（但这是 AI 助手的优势）
- 需配通构建环境


### 3.2 硅胶物理模型

#### 3.2.1 线宽-速度映射

```
已知常量：
  Q  = 挤出速率 (mm³/s)，由气压、针筒、喷嘴决定
  H  = 层高 (mm)
  F  = 移动速度 (mm/s)
  W  = 线宽 (mm)

关系：
  Q = W × H × F
  → W = Q / (H × F)
  → F = Q / (W × H)

可实现的线宽范围（由速度上下限决定）：
  W_min = Q / (F_max × H)
  W_max = Q / (F_min × H)
```

#### 3.2.2 标定参数（20psi, 0.84mm 喷嘴, 30CC/50CC 针筒）

| 参数 | 值 | 说明 |
|---|---|---|
| 最佳移动速率 | 10 mm/s | 对应线宽 1.24mm（PrusaSlicer 设定） |
| 挤出速率 Q | 10 × 1.24 × 0.6 = **7.44 mm³/s** | 由最佳速率反推 |
| 开气延迟 | 150 ms | 开气到出料稳定 |
| 关气延迟 | 400 ms | 关气后余料停止 |
| 真空回抽时间 | 待标定 | 真空阀开启时长 |
| 速度下限 F_min | 待定（如 2 mm/s） | 最慢速度 → 最宽线宽 |
| 速度上限 F_max | 待定（如 30 mm/s） | 最快速度 → 最窄线宽 |

#### 3.2.3 时序控制

```
挤出开始序列：
  M106              ; 开气泵
  G4 P{on_delay}    ; 等待出料稳定（150ms）
  G1 X... Y... F... ; 挤出移动（F 由线宽决定）

挤出结束序列：
  M107              ; 关气泵
  G4 P{off_delay}   ; 等待余料停止（400ms）

真空回抽序列（待标定）：
  M107              ; 关气泵
  M106 P2 S255      ; 开真空阀
  G4 P{vacuum_time} ; 真空回抽
  M106 P2 S0        ; 关真空阀
```

#### 3.2.4 速度斜坡（消除头尾堆料）

```
挤出开始：
  F 从 F_min（或 F_target × 0.3）渐变到 F_target
  斜坡长度：2mm（可配置）

挤出结束：
  F 从 F_target 渐变到 F_min
  斜坡长度：2mm（可配置）
```

### 3.3 具体改动内容

#### 3.3.1 PrintConfig.cpp/hpp — 新增硅胶配置项


#### 3.3.2 Flow.cpp/hpp — 挤出模型翻转为速度模型

```cpp
// 原 FDM 逻辑：
// float extrude_volume = spacing × layer_height × extrusion_width;

// 新增硅胶逻辑：
```

```cpp
// 原 FDM 回抽：

// M106 P2 S255      ; 开真空阀（如使用）
// G4 P{vacuum_time} ; 延时
// M106 P2 S0        ; 关真空阀
```

```cpp

// 硅胶输出：

// 挤出移动：G1 X{x} Y{y} F{speed}
// 挤出结束：M107 + G4 P{off_delay}
```

```cpp

// 硅胶速度斜坡：
//   M106 + G4 P{on_delay}
//   然后 F 从 min_speed 渐变到 target_speed（在 ramp_length 内）
```

### 3.4 路径规划中的线宽约束

硅胶模式下，路径规划需感知可实现的线宽范围 `[W_min, W_max]`：

- **周长路径**：使用 W_max（最佳表面质量），速度 = F_min
- **填充路径**：使用 W_max，间距 = W_max
- **薄壁处理**：区域宽度 < 2×W_min → 单条路径，线宽 = 区域宽度（clamp 到 [W_min, W_max]），速度 = Q/(线宽×H)
- **填缝处理**：周长与填充之间的缝隙宽度 g ∈ [W_min, W_max] → 插入路径，线宽 = g，速度 = Q/(g×H)
