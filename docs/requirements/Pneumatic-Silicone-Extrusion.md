# 气动硅胶挤出需求补充

状态：需求修订草案。本文只记录已知事实与待确认事项，不代表相关功能已经实现或验收。

## 1. 新确认的事实

用户已确认：
- 项目目标是为特定硅胶／液态材料打印机定制 PrusaSlicer。
- 目标设备采用气动挤出，工艺不同于 FDM。
- 核心混料能力尚未确定，需要先根据仓库代码和实际设备需求判断。

目标设备型号、固件、控制器、气压控制接口、材料组分数和所需混料行为仍待确认。

## 2. 对项目定位的影响

FDM 通常通过送料机构推进固体丝材；气动挤出通常使用气压推动料筒中的材料。不能直接假定 FDM 的送料量模型、回抽策略或颜色预测算法可直接用于硅胶气动挤出。

因此，当前需求主线应从“实现通用混料功能”调整为：

1. 明确目标设备与气动出料控制接口。
2. 明确切片路径、移动速度和材料沉积量之间的关系。
3. 生成设备实际支持的运动和出料控制指令。
4. 通过静态文件检查及受控设备测试验证出料起停和沉积结果。
5. 只有在设备确实具备相应计量硬件、且用户确认有需要时，再决定是否支持多组分配比、逐层变化或空间变化。

## 3. 气动挤出需求候选项（均待确认）

- 气压由手动调压阀、电子压力调节器、控制板、PLC 或其他设备控制。
- 设备接受的命令格式、压力单位、参数范围及执行时序。
- 打印开始和结束时需要的出料启动、停止及等待行为。
- 是否需要压力补偿、提前量或其他动态处理。
- 是否支持回抽；如果不支持，如何处理停料、滴料和拉丝。
- 材料流量的校准方法，以及线宽、层高、移动速度与沉积量之间的映射。
- 若为多组分材料，组分数量、各自的计量方式和混合位置。

这些是调查问题，不代表目标设备一定需要所有功能。未拿到设备资料前，不应臆定具体 G-code、压力单位、控制策略或数值阈值。

## 4. 重新评估现有代码

| 现有代码方向 | 需求判断原则 |
|---|---|
| `prusa_fdm_mixer` 颜色预测 | 不能证明气动挤出核心功能已实现；仅在确有颜色预测需求且模型适用于目标材料时纳入范围 |
| 虚拟挤出机 | 需确认它代表逻辑配方、材料通道还是 FDM 物理挤出机；不能直接视为气动通道控制 |
| 逐层比例与多材料分段 | 只有设备具备对应的独立计量能力时，才可能转化为真实可执行功能 |
| G-code 输出 | 需要与目标固件／外部控制器的实际命令契约逐项核对 |
| 3MF 保存与恢复 | 仍可作为项目可靠性候选需求，但要保存的气动参数与配方须先定义 |

以上是需求审查原则，不是对未检查代码路径的否定。

## 5. 优先级和验收标准

### P0：确认设备接口

需记录打印机型号、控制器／固件、气压控制方式、出料控制命令、单位、允许范围及可用参考文件。

验收：开发者可以依据文档判断每条输出命令的含义、参数单位和执行顺序；每个关键事实都有设备资料或可复现样例支持。

### P0：建立沉积量校准方法

确定设备是否能测量或控制流量；如不能，定义可重复的测试路径和测量方式。允许误差由用户或工艺测试确定，不预设未经验证的数字。

验收：在记录设备设置、材料和测试条件后，可重复测量固定路径的沉积结果。

### P1：验证切片到机器输出的完整链路

验收：对固定测试模型生成输出文件，自动检查路径、速度和设备实际支持的出料控制命令；随后在经过风险评估的受控条件下验证目标设备。静态文件检查不能替代实机测试。

### P2：决定高级混料能力

仅在用户确认实际需求及设备计量能力后，决定是否开发固定比例、逐层配比、区域配比、颜色预测或配方管理。

## 6. 最小可验收目标（初稿）

- 使用目标设备配置切片一个简单测试模型。
- 生成目标设备实际支持的运动和出料控制文件。
- 对关键命令、参数、单位和顺序进行静态检查。
- 用固定测试路径和记录完整的材料／设备条件验证沉积行为。
- 保存并重新打开项目，检查已定义的设备配置和切片设置是否保留。

在设备接口、测试模型及允许误差确定前，该目标状态为“方向已明确，验收细节待确认”。

## 7. 需要用户补充的资料

1. 打印机品牌／型号，或控制器与固件名称。
2. 气压控制方式：手动调压、电子调压器、控制板、PLC 或其他方式。
3. 当前成功打印所用的命令格式；如有，可提供去除敏感信息的参考输出文件。
4. 材料是单组分硅胶还是多组分体系；如为多组分，如何分别计量和混合。
5. 当前首要问题是无法生成可用路径，还是路径可以执行但出料量、起停、拉丝或沉积一致性不理想。
