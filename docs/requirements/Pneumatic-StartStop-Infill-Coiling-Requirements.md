# 新增需求：气动硅胶启停、填充间距与 Liquid Rope Coiling（2026-10-12）

状态：用户需求补充；待结合代码进一步实现和测试。
分支：`docs/requirements-baseline`
前提：单组分材料、手动调压且打印时基本恒压；当前优先目标为生成适用 G-code。
硬件边界：未提供控制器、固件或硬件协议。不得假定任何特定阀门、压力控制或等待命令。

## 1. 用户明确报告的现状

1. 当前启停能力不满足需要：
   - 不支持在空行程／非沉积移动期间关闭气压。
   - 不支持“先开启气压、等待稳定后再移动沉积”的操作。
   - 不支持“提前关闭气压，再完成剩余移动／路径”的操作。
2. 部分填充模式只能按填充率（百分比）设置，不能按填充线间距设置。
3. 计划使用 Liquid Rope Coiling（液体绳卷绕）打印泡沫结构：
   - 需要把喷嘴抬高；
   - 该工艺中喷嘴高度不能简单等同于普通 FDM 的线宽／层高关系；
   - 目前缺少可独立设置的喷嘴高度和打印过程中需要保持的间距参数。

以上为用户描述的需求／当前使用体验；并非本次对每个填充模式和所有代码路径完成穷尽性验证后的代码结论。

## 2. P0：出料启停与非沉积移动

### 2.1 目标行为（逻辑需求，不预设实际 G-code 命令）

需要把“机器移动”和“材料出料状态”分离建模。期望支持以下可配置的逻辑阶段：

- 出料启动：发出经设备协议确认的启动动作。
- 启动等待：可配置稳定等待时间；等待期间不开始沉积路径。
- 沉积移动：沿路径移动并按硅胶模式计算移动速度。
- 提前停止出料：在路径终点之前按配置距离或可验证的时序停止出料，以补偿残余流动。
- 非沉积移动：执行 travel move 时材料应处于由设备实际能力决定的安全／不出料状态。
- 路径结束与程序结束：输出状态应明确，避免意外持续出料。

这些是期望的逻辑行为。由于用户尚未提供硬件协议，不能把“关闭气压”直接实现成假定的 M-code。特别要区分：
- 关闭供气；
- 关闭材料阀；
- 通过真空／负压停止出料；
- 仅暂停运动而材料仍可能继续流出。

这些动作物理意义不同，不可互相替代。

### 2.2 配置建议

在确认设备控制方式后，考虑以下独立参数：

- 出料启动延迟（时间）。
- 出料提前停止量（沿路径距离，或经验证的等效时序；避免未经验证就混用距离与时间）。
- 空行程期间的出料状态策略。
- 如设备支持，独立的出料启动／停止动作配置。
- 起停补偿开关与安全默认行为。

不应仅依赖当前 `silicone_pressure_on_delay` / `silicone_pressure_off_delay` 参数名称来认定行为已经实现。必须验证参数是否真正影响输出、输出顺序是否正确、单位换算是否一致，以及所有路径类型是否覆盖。

### 2.3 必须覆盖的输出测试

- 起动动作、等待、首段沉积的顺序。
- 最后一段沉积结束前的提前停止。
- 沉积路径与 travel path 交替。
- 相邻短路径、短于提前停止距离的路径。
- 层开始／层结束、换区移动、空走、暂停与程序结束。
- 在无设备协议的单元测试中，只检查抽象事件顺序或使用测试替身；不能把假设的硬件命令写成验收期望。

## 3. P1：填充间距控制

### 3.1 需求

对适用的填充模式，除了百分比填充率，还应允许用户以实际几何间距控制填充线布局（单位与参数名称遵循项目现有约定，通常应清楚标注为 mm）。

### 3.2 设计边界

- 填充率是面积／体积占比类的抽象参数；填充线间距是几何参数，两者并不总能在不同图案、线宽和边界裁切下简单互换。
- 不应假设所有填充算法都天然支持相同的间距语义。
- 应先列出仓库支持的填充模式，逐个确认哪些可以自然采用间距参数、哪些需要转换、哪些不适用。
- 当用户选择间距模式时，UI 应明确当前生效的控制方式，避免填充率和间距同时生效但含义不清。
- 测试应覆盖线宽变化、窄区域、边界裁切、不同填充角度、稀疏／密集填充及不合理参数范围。

### 3.3 验收方向

给定相同模型、填充图案、线宽与填充间距时，改变模型尺寸不应意外改变内部规则间距；边界处可以因裁切产生局部变化。验收前需明确哪些填充模式纳入首期范围。

## 4. P1：Liquid Rope Coiling 泡沫打印的独立喷嘴高度／间距

### 4.1 需求

增加与普通 FDM 层高和挤出线宽概念分离的几何控制，以支持 Liquid Rope Coiling（液体绳卷绕）：

- 可独立设置喷嘴相对基准面的高度或 Z 偏移。
- 可设置打印过程中需要保持的喷嘴—已沉积材料／基准面间距。
- 明确高度是相对打印床、当前切片层面、已沉积材料顶面，还是用户指定基准面。
- 明确参数在每层、每段路径、travel move、首层和结束阶段的适用规则。

### 4.2 不应做的假设

- 不应把喷嘴直径／半径自动当作应保持的间隙。
- 不应把普通 FDM 的层高直接当作液体绳卷绕的喷嘴—材料间距。
- 不应默认单一固定 Z 偏移就能代表所有泡沫卷绕路径。
- 不应在未明确高度基准的情况下直接修改 Z 运动。

### 4.3 需要进一步确定的几何定义

- 用户所说“喷嘴抬高”的基准：相对于打印床、切片模型表面，还是沉积后的泡沫／液体绳顶面。
- 目标间距是固定值、随路径变化，还是随层／卷绕圈变化。
- 当前 Z 轴是否仍按常规逐层上升；还是应由工艺参数单独控制。
- 喷嘴移动到起始点、空行程和结束回撤时采用何种 Z 高度。
- 切片模型的几何高度是否仍代表最终打印件的几何高度，尤其是卷绕空隙／泡沫结构。

在这些定义确定前，先完成参数语义与 G-code 规划，不应臆造具体算法。

## 5. 与现有仓库实现的关系

先前静态审查确认仓库已有 `silicone_mode`、`silicone_flow_rate`、起停延迟、真空回抽时间和速度计算的代码结构；但这些存在不等于所需行为已满足。

下一轮代码审查应重点定位并核实：

1. 硅胶模式的实际出料启动／停止文本在哪个 writer 函数生成。
2. 空行程生成时是否执行出料停止；如果没有，所有 travel 路径的控制点在哪里。
3. 启停等待参数是否真正生成等待动作；输出顺序是否符合用户需要。
4. 是否有“提前停止”的距离补偿实现；若没有，需明确在路径生成阶段如何安全裁剪沉积段。
5. 填充率／间距配置与各填充生成器之间的映射。
6. Z 运动的生成路径：层切换、路径 Z、travel Z、首层、结束代码，以及硅胶模式是否能覆盖或参数化这些逻辑。
7. 为以上行为增加可复现的单元测试／G-code golden tests，并保留常规 FDM 模式的回归测试。

## 6. 建议的优先级

| 优先级 | 工作项 | 原因 |
|---|---|---|
| P0 | 建立抽象出料启停状态与输出顺序测试 | 当前 travel 与出料控制的逻辑需求不满足 |
| P0 | 明确启动等待与提前停止的语义 | 现有参数名称不足以证明输出行为正确 |
| P0 | 定义设备协议边界；硬件命令保持可替换 | 防止生成设备无法执行的 G-code |
| P1 | 对填充模式逐一增加／映射间距控制 | 用户目前只能用填充率控制部分填充 |
| P1 | 定义独立的 coiling Z／间距基准与参数 | 普通 FDM 层高模型不能直接表达所需几何 |
| P2 | 根据测试结果优化起停补偿和卷绕几何 | 依赖 P0/P1 的语义与测量结果 |
