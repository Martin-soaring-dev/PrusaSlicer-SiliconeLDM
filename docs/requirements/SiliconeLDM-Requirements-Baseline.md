## 1. 项目目标与边界

### 1.1 已确认目标

用户已明确：项目最初目标是**为特定硅胶／液态材料打印机定制 PrusaSlicer**。

用户尚未确定核心混料能力，要求先检查现有代码，再据此梳理需求。当前阶段应先完成需求和实现盘点，不应仅凭推测继续扩展混料功能。

### 1.2 尚未确认的项目定义

以下信息会直接影响架构和验收，当前没有足够证据定论：

- 目标打印机的品牌、型号、运动控制器和固件。
- 材料是单组分还是多组分；若为多组分，组分数量、比例范围和计量方式是什么。
- 设备接受的控制接口：普通挤出 G-code、独立泵／阀命令、专用宏，或其他协议。
- 混合发生在喷嘴前、静态混合器、打印头内部还是其他位置。
- 设备是否要求比例随层变化、随模型区域变化，或仅需固定配比。
- 颜色预测是否是实际工艺需求，还是现有 FDM 混料实现的一项辅助功能。
- 目标操作系统、打包方式、PrusaSlicer 上游基线版本和升级策略。
- 是否已有可用于回归测试的设备、材料配方、校准样本和成功打印文件。

在这些问题得到确认前，不应把“通用多材料颜色混合器”当作项目的最终定位。

## 3. 需求状态分类

### 3.1 已确认需求（来自用户）

**R-001 — 目标产品定位**  
提供面向某种特定硅胶／液态材料打印机的 PrusaSlicer 定制版本。

验收条件：
- 项目文档明确目标设备及其材料／挤出工艺。
- 至少有一套设备配置和一个可重复使用的验证模型。
- 能从模型切片生成目标设备可接受的输出文件。
- 设备与输出协议尚未确认前，本需求保持“待细化”，不宣称通过验收。

**R-002 — 先盘点再定核心混料功能**  
在确认核心混料需求前，先核对现有实现和缺口，不凭空增加未确认的功能要求。

验收条件：
- 需求文档将用户确认事项、代码证据、推测和待确认项分开。
- 每项拟进入开发的功能都有对应验收条件。
- 混料功能的优先级由实际工艺需求决定，而不是由现有代码结构决定。

### 3.2 从代码确认的实现方向（尚非用户确认的最终需求）

- 虚拟挤出机与多组分比例表达。
- FullSpectrum 混料配置 UI。
- 逐层分辨率相关逻辑和多材料分段映射。
- FullSpectrum 配置写入／读取 3MF。
- FDM 混合颜色预测。

这些项目应作为代码审查清单；是否保留、修改或删除，需在设备需求确认后决定。

### 3.3 尚未证实／尚未验收的能力

- 目标打印机特定的 G-code 或其他机器命令输出。
- 从 UI 配置、切片内部数据到最终输出命令的完整数据链路。
- 混料比例与泵／挤出流量、材料计量之间的正确映射。
- 对目标材料的校准、混合响应、延迟和冲洗行为处理（是否需要由工艺确认）。
- 目标设备上的实际打印验证。
- 自动化测试、持续集成构建和发布包验证。
- 3MF 保存后重新打开时，虚拟挤出机、比例、颜色、分段映射等状态的一致性。

以上是“目前缺少足够证据”，不等同于断言仓库中绝对没有相应代码。

## 4. 建议的需求优先级

### P0 — 明确设备与输出契约

在扩展混料功能前，必须记录：
1. 目标打印机／控制器／固件。
2. 输入材料、组分数量及计量硬件。
3. 机器命令协议及一份已知可工作的参考输出文件。
4. 设备配置、坐标／单位约定、流量或泵速的解释方式。
5. 可重复的最小打印测试模型和安全测试流程。

验收：另一位开发者仅依照文档，就能判断生成文件应包含哪些机器命令，以及如何在不进行危险实际打印的前提下做静态检查。

### P1 — 证明端到端切片闭环

- 明确从材料／配比输入到切片内部数据，再到最终机器输出的每个转换步骤。
- 确保目标设备所需的命令被生成，且普通 FDM 假设不会错误地替代专用液态材料控制逻辑。
- 对单组分／多组分、零比例、极限比例、非法配置和缺失配置制定预期行为。
- 验证生成文件中的比例、单位、顺序和总量符合设备协议。

验收：使用固定配置和测试模型，自动检查输出命令与预期结果；在获得设备与材料验证条件后，再执行受控实机测试。

### P1 — 配置与项目文件可靠性

- 保存并重新打开 3MF，检查虚拟挤出机定义和相关映射是否一致。
- 测试物理挤出机数量变化、旧格式文件、未知配置版本和非法 JSON。
- 不允许虚拟 ID 静默映射到错误的物理通道。

验收：建立自动化往返测试和异常输入测试；失败时应给出可理解的错误或安全回退，而不是输出错误通道。

### P2 — 决定混料高级能力

分别评估以下候选项，只有确认有实际需求后才纳入承诺范围：
- 固定比例混合。
- 按层改变比例。
- 按模型区域／体素／路径位置改变比例。
- 根据目标颜色反算比例。
- 颜色预测和可视化。
- 配方保存、复用和校准。

验收：每个被选中的能力都要有独立示例、边界条件和测试；未选择的能力明确标为非目标或后续规划。

### P2 — 可维护性与交付

- README 说明项目用途、目标设备、支持范围、构建方法和限制。
- 记录上游 PrusaSlicer 基线版本和同步策略。
- 明确自动化构建、测试及发布产物的验证方式。
- 检查是否误提交大型构建产物或本地环境文件。

验收：干净环境能够按文档构建；版本和发布说明可追踪；关键测试结果可复现。

## 6. 明确不纳入当前承诺的内容

在用户确认之前，不把以下事项视为必须交付：
- 通用多色 FDM 打印功能。
- 精确颜色反算或颜色匹配精度承诺。
- 连续空间渐变或任意分辨率混料。
- 对所有硅胶／液态材料打印机的通用兼容。
- 已达到生产可用、可发布或通过实机验证的结论。

## 7. 下一步需要确认的信息

按优先级确认以下问题：
1. 目标打印机的品牌／型号、固件和控制器是什么？
2. 是单组分材料，还是多组分混合？若是多组分，实际由什么硬件计量和混合？
3. 目前有没有一份可工作的机器输出文件或其他软件生成的参考 G-code？
4. 最初的成功标准是“能够切片并驱动打印机”，还是必须实现某种特定混料／渐变效果？
5. 是否有目标设备和材料可用于实际验证？

在这些问题得到回答之前，本文件应保持为“待确认需求基线”，不应据此宣称项目功能已经验收或发布就绪。
